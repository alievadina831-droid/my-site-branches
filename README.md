# My Site

Бұл репозиторийде Git үйренуге арналған шағын сайттың коды сақталады (HTML, CSS, JS).

## Әзірлеуді баптау

1. Репозиторийді клондау немесе папканы көшіру.
2. Папканы VS Code-та ашу.
3. `index.html` файлын браузерде ашып, нәтижені көру.

## Қосымша құжат

Тармақтармен жұмыс ережелері осы жұмыс нұсқаулығында сипатталған: "Git тармақтарымен жұмыс" (қосымша басшылық құжат).
